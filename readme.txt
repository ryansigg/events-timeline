An Event post type and a Timeline block, with type filters you can link to.

== Description ==

Add events with a start and end date, a location and an optional link, then show them anywhere with the Events Timeline block.

* Upcoming events (including ones happening now), past events, or both.
* Horizontal or vertical layout. Horizontal timelines become a vertical list on phones.
* Filter buttons for each event type. The filter is kept in the address bar, so a filtered view can be shared or bookmarked, and it works without JavaScript.
* Uses your theme's colors and fonts. Supports alignment, color, spacing and font size settings.
* Accessible: real lists and headings, `<time>` elements, pressed states on filters, a live count for screen readers, and a keyboard-reachable scroll area.

== Installation ==

1. Upload the plugin and activate it.
2. Add event types under Events > Event types, then add events under Events > Add New Event. The Event details panel in the sidebar holds the dates, location and link.
3. Add the Events Timeline block to any page.

== Frequently Asked Questions ==

= Can I link straight to one type of event? =

Yes. Add `?event_type=` and the type's slug to the page address, for example `/events/?event_type=tournament`.

= Which time zone are event times in? =

The site's time zone, from Settings > General.
